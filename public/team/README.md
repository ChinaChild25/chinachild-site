# Фото преподавателей

Положите портреты преподавателей сюда. Файл подключается через поле `image` в `lib/site-data.ts`.

## Формат

- **Размер**: 800×800 px (квадрат, центр кадра — лицо)
- **Формат**: WebP (лучшее сжатие, поддерживается всеми браузерами 2026)
- **Альтернативный формат**: JPG fallback необязателен — `next/image` сам конвертирует
- **Размер файла**: цель ≤ 80 KB на портрет

## Имена файлов

Используйте slug преподавателя из `lib/site-data.ts`:

- `anastasia-ponomareva.webp`
- `anastasia-erina.webp`
- `zhao-li.webp`

## После загрузки

1. Скопируйте файл в эту папку
2. Откройте `lib/site-data.ts`
3. Найдите преподавателя по slug
4. Замените `image: ""` на `image: "/team/<slug>.webp"`
5. Закоммитьте — Vercel задеплоит сам

## Заглушка

Пока поле `image` пустое, на странице рендерится цветной кружок с инициалами.
Это нормально для demo, но для E-E-A-T в SERP Google критически нужны
реальные фото — образование относится к YMYL-нише, и Google смотрит на
"реальных людей за контентом".

## Сертификаты и дипломы

Сканы HSK и дипломов — в подпапке [`certificates/`](./certificates/README.md).
Список файлов и поля в `site-data.ts` уже настроены; достаточно загрузить WebP.

## Опционально: групповое фото

`group-photo.webp` (1600×900) — общее фото команды для страницы /about.
Подключается отдельно: правьте `app/about/page.tsx`, секция «Команда».
