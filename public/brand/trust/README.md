# Trust platform logos

Put real platform logos here. Do not use AI files directly on the website:
export AI to SVG or transparent PNG first.

Preferred file names:

- `vk-light.svg` — light/white VK logo for dark surfaces
- `vk-dark.svg` — dark VK logo for light surfaces
- `vk.svg` — fallback if only one version exists

- `youtube-light.svg`
- `youtube-color.svg`
- `youtube.svg`

- `vc-light.svg`
- `vc-dark.svg`
- `vc.svg`

- `edutop-light.svg`
- `edutop-color.svg`
- `edutop.svg`

- `zoon-light.svg`
- `zoon-color.svg`
- `zoon.svg`

Rules:

- Use SVG when available.
- Use PNG only when SVG is unavailable; transparent background is required.
- Keep the logo artboard tight, without extra empty margins.
- Do not include outlines or card backgrounds inside the logo file. The site
  provides the shape/background.
