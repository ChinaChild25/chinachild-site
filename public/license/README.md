# Лицензия — сканы документов

Сканы образовательной лицензии для страницы `/license` и блока в подвале.

## Формат

- **Размер**: 1200×800 px (горизонтальный документ) или 800×1200 (вертикальный)
- **Формат**: WebP (`license-scan.webp`), желательно дополнительно JPG fallback
- **Размер файла**: цель ≤ 200 КБ
- **Содержимое**: документ должен быть читаем — заголовок, номер, дата, подпись

## Имена файлов

- `license-scan.webp` — основная страница (титульный лист с реквизитами)
- `license-app-1.webp`, `license-app-2.webp` *(опционально)* — приложения с программами

## После загрузки

1. Скопируйте `license-scan.webp` сюда
2. Откройте `app/license/page.tsx`
3. Раскомментируйте блок `<Image src="/license/license-scan.webp" ... />`
4. Удалите блок-заглушку с инструкцией (комментарий выше `<Image>`)
5. Закоммитьте

## SEO-смысл

Реальное фото лицензии — это сильный E-E-A-T сигнал для Яндекса и Google.
Любая «образовательная» страница без подтверждающего документа считается
менее авторитетной. Plus: на /license уже подключен schema.org
`EducationalOccupationalCredential` — он будет «иметь смысл» только если
рядом есть визуальное подтверждение.

## Privacy

Если на скане видны персональные данные подписавших чиновников или печать
содержит ИНН — обязательно затрите их в графическом редакторе перед публикацией.
ФИО и должность ответственного лица обычно публикуются без проблем (открытые
данные).
