# Скриншоты платформы ChinaChild

Положите скриншоты или GIF-демо функций платформы сюда. Подключаются
через поле `media` в массиве `features` в
`components/sections/PlatformShowcase.tsx`.

## Формат

- **Пропорции**: 16:10 (например, 1280×800 или 1600×1000)
- **Формат**: WebP для статики, GIF/MP4 для анимации
- **Размер файла**: ≤ 200 KB для WebP, ≤ 1 MB для GIF

## Имена файлов

Соответствуют id фичи:
- `video-calls.webp` — видеозвонки в браузере
- `schedule.webp` — расписание занятий
- `ai-trainer.webp` — AI-тренажёр иероглифов
- `recordings.webp` — записи уроков
- `progress.webp` — трек прогресса HSK

## После загрузки

Откройте `components/sections/PlatformShowcase.tsx`, найдите массив
`features` и замените `media: ""` на путь, например:

```ts
{
  id: "video-calls",
  media: "/platform/video-calls.webp",
  ...
}
```

## SEO-смысл

`alt` у каждого <img> уже задан — Google и Yandex.Картинки будут
индексировать скриншоты как отдельные ассеты. Для лендинга «онлайн-школа
китайского» это полезно: пользователь видит реальный продукт перед
заявкой, поведенческие улучшаются.
