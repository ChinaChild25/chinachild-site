# Home Hero Orbit Photos

Put final first-screen portrait assets here.

Recommended format:

- `top-left.webp`
- `top-right.webp`
- `left.webp`
- `right.webp`
- `bottom-left.webp`
- `bottom-right.webp`

Requirements:

- square crop, at least `800x800`
- WebP or PNG
- face centered with some shoulder/torso room
- transparent background is OK, but regular photo backgrounds also work

After adding final files, update `orbitItems` in `components/sections/HeroSection.tsx`.
