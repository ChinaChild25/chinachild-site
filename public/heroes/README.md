# Иллюстрации для PageHero

Картинки в правой части hero-блоков на десктопе и под текстом на мобильных.
Используются в компоненте `<PageHero illustration="..." />`.

## Технические требования

| Параметр | Значение |
|---|---|
| **Разрешение** | 1200–1600 px по длинной стороне для обычных иллюстраций; исходный размер можно оставить, если файл после сжатия остаётся лёгким |
| **Формат** | WebP для растровых ассетов; SVG только если нужен вектор или точный срез по краю |
| **Размер файла** | Цель ≤ 200 KB, допустимо до 300 KB для сложной графики |
| **Цветовой профиль** | sRGB |
| **Прозрачный фон** | Ок, если hero-карточка задаёт нужный фон |
| **Название файла** | Человеко-понятный slug латиницей: `kitajskij-slovar.webp`, `grammatika-kitajskogo-yazyka.webp` |

Next.js генерирует responsive-варианты через `next/image`. Hero-изображения
подключаются с `priority`, поэтому не кладите сюда тяжёлые PNG без сжатия.

## Куда класть файлы

`/public/heroes/<tema-ili-stranica>.webp` — slug соответствует теме или пути URL.

Примеры:
- `/public/heroes/glossary.webp` → используется на `/glossary`
- `/public/heroes/kitajskij-slovar.webp` → `/dictionary`
- `/public/heroes/grammatika-kitajskogo-yazyka.webp` → `/grammar`
- `/public/heroes/gruppa-ili-individualno.webp` → `/compare/mini-group-vs-individual`

## Как подключить в компоненте

В файле страницы (например, `app/glossary/page.tsx`) добавьте проп
`illustration` к `<PageHero>`:

```tsx
<PageHero
  variant="lime"
  eyebrow="Глоссарий"
  title="Термины и понятия китайского языка"
  description="..."
  primaryCta={{ label: "Записаться на пробное", modal: true }}
  illustration="/heroes/glossary.webp"
  illustrationAlt="Иероглиф 汉 — символ ханьского письма в глоссарии ChinaChild"
  illustrationWidth={1201}
  illustrationHeight={1065}
  illustrationFill
/>
```

## SEO-важно

`alt` — это не подпись для пользователя, а текст для поисковиков и
скринридеров. Хороший alt:

- Описывает реальное содержимое картинки (что изображено)
- Содержит ключевые слова темы страницы
- Длина 60–120 символов
- Без слов «картинка», «изображение», «фото» — поисковик и так это знает

Плохо: `alt="главная картинка глоссария"`
Хорошо: `alt="Иероглиф 汉 — символ ханьского языка и письменности, главного предмета глоссария ChinaChild"`

## Где взять иллюстрации

1. **Свои дизайн-ассеты** — лучший вариант, уникальный SEO
2. **Бесплатные с фигмы / dribbble** — проверяйте лицензии на коммерческое использование
3. **AI-генерация (Midjourney, DALL-E, Imagine)** — указывайте стиль «flat illustration, soft pastels, Yandex Practicum style»

После генерации обязательно прогоните через:

```bash
cwebp -q 82 -m 6 input.png -o output.webp
```

Если исходник уже WebP, но весит слишком много, можно так же пересжать его в
новый файл и заменить путь в коде.

## Что уже подключено

См. в коде:

```bash
rg 'illustration="/heroes/' app lib
```

## Адаптивная вёрстка

Компонент `<PageHero>` держит стабильные размеры через CSS. Для иллюстраций с
явными срезами по правому или нижнему краю используйте `illustrationFill` и
приклеивайте кадр к нужной границе через класс hero-карточки в `app/globals.css`.
Для иллюстраций без срезов оставляйте отступы и центрирование внутри shape.

После добавления новой картинки:

- добавьте понятный `illustrationAlt` на странице;
- добавьте запись в `app/sitemap-images.xml/route.ts`, если это отдельная SEO-страница;
- проверьте, что старый PNG/SVG больше не используется: `rg "старое-имя" app lib public`;
- удаляйте исходники только после замены всех ссылок.
