# Иллюстрации для PageHero

Картинки в правой колонке hero-блоков (на десктопе) или под текстом
(на мобиле). Используются в компоненте `<PageHero illustration={...} />`.

## Технические требования

| Параметр | Значение |
|---|---|
| **Разрешение** | 1200×1200 px (квадрат) или 1200×900 (4:3 ландшафт) |
| **Формат** | WebP (предпочтительно), AVIF тоже ок |
| **Размер файла** | ≤ 200 KB |
| **Цветовой профиль** | sRGB |
| **Прозрачный фон** | Желательно — иллюстрация лежит на цветной hero-карточке |
| **Стиль** | Yandex-style — иллюстративный, не фото |

Next.js автоматически конвертирует WebP в AVIF для поддерживающих
браузеров, генерирует ретина-варианты (1×, 2×) и lazy-loading для всех,
кроме `priority: true`.

## Куда класть файлы

`/public/heroes/<slug-страницы>.webp` — slug соответствует пути URL.

Примеры:
- `/public/heroes/glossary.webp` → используется на `/glossary`
- `/public/heroes/about.webp` → `/about`
- `/public/heroes/methodology.webp` → `/methodology`
- `/public/heroes/blog.webp` → `/blog`
- `/public/heroes/courses.webp` → `/courses`

## Как подключить в компоненте

В файле страницы (например, `app/glossary/page.tsx`) добавьте проп
`illustration` к `<PageHero>`:

```tsx
<PageHero
  variant="lime"
  eyebrow="Глоссарий"
  title="Термины и понятия китайского языка"
  description="..."
  primaryCta={{ label: "Записаться на пробное", modal: true }}
  illustration={{
    src: "/heroes/glossary.webp",
    alt: "Иероглиф 汉 — символ ханьского письма, главного предмета глоссария",
    priority: true, // только если страница — точка входа (главная и т.п.)
  }}
/>
```

## SEO-важно

`alt` — это не подпись для пользователя, а текст для поисковиков и
скринридеров. Хороший alt:

- Описывает реальное содержимое картинки (что изображено)
- Содержит ключевые слова темы страницы
- Длина 60–120 символов
- Без слов «картинка», «изображение», «фото» — поисковик и так это знает

Плохо: `alt="главная картинка глоссария"`
Хорошо: `alt="Иероглиф 汉 — символ ханьского языка и письменности, главного предмета глоссария ChinaChild"`

## Где взять иллюстрации

1. **Свои дизайн-ассеты** — лучший вариант, уникальный SEO
2. **Бесплатные с фигмы / dribbble** — проверяйте лицензии на коммерческое использование
3. **AI-генерация (Midjourney, DALL-E, Imagine)** — указывайте стиль «flat illustration, soft pastels, Yandex Practicum style»

После генерации обязательно прогоните через `cwebp -q 80 input.png -o output.webp`
для сжатия до целевого размера ≤200 KB.


## Адаптивная вёрстка

Компонент `<PageHero>` сам решает, как разместить:

- **Десктоп ≥1024px**: 2-колоночный grid `[1.05fr_0.95fr]`. Текст слева, картинка справа в квадрате 1:1.
- **Планшет 768–1023px**: единая колонка. Текст сверху, картинка снизу с aspect 4:3.
- **Мобиль <768px**: единая колонка. Текст сверху, картинка снизу 4:3, занимает всю ширину карточки минус padding.

Aspect-ratio задаёт стабильное место на странице ДО загрузки картинки —
zero CLS даже на медленном интернете.
