# Cutover archive

Status: historical migration evidence.

The files in this folder record the Tilda-to-Vercel domain cutover and the state
observed on their individual dates. They are intentionally retained for
redirect provenance and operational history.

They are not current production-status documents. For active decisions use:

- `AGENTS.md` for the agent contract.
- `ARCHITECTURE.md` for current boundaries and data flows.
- `next.config.ts` and `redirect-map.csv` for implemented redirect behavior.
- Current production checks for external state.

Do not delete redirect evidence solely because the migration is complete.
