## 3. Проверка гипотезы «поисковики любят подробные статьи с таблицами»

Гипотеза проверена корреляцией структуры всех 47 статей с трафиком,
нормированным на возраст статьи (визитов в день).

| Признак | Корреляция с визитами/день |
| --- | --- |
| Количество таблиц | **+0,33** |
| Блоки callout | +0,23 |
| Пунктов в FAQ | +0,20 |
| Объём текста | +0,15 |
| Аудиоблоки | +0,16 |
| Заголовки H2 | +0,19 |
| Пунктов в TL;DR | −0,05 |
| Внутренних ссылок | 0,00 |
| Возраст статьи | −0,11 |

**Вывод: гипотеза подтверждается частично и не является главным фактором.**
Таблицы — самый сильный структурный признак, но связь умеренная. Решающие
контрпримеры:

- `kitayskiy-dlya-it-tekh-glossariy-200` — самая проработанная статья блога
  (12 таблиц, 3 306 слов, 15 разделов H2) → **7 визитов** за 41 день.
- `how-to-learn-chinese-from-scratch` — 2 таблицы, без FAQ и TL;DR, 1 330 слов
  → **1 164 визита**.

Структура помогает удержать позицию по запросу, за который вы уже боретесь.
Потолок трафика задаёт **спрос на тему**.

### Что реально отличает победителей от проигравших

| Победители (>5 визитов/день) | Проигравшие (<0,2 визита/день) |
| --- | --- |
| Широкий информационный вопрос | Коммерческое сравнение |
| `100-fraz-na-kitayskom` — 1 788 | `repetitor-vs-onlayn-shkola` — 3 |
| `hsk-3-0-novyy-format-2027` — 2 141 | `gruppa-ili-individualno` — 2 |
| `professii-svyazannye-s-kitayskim` — 123 за 13 дней | `kak-vybrat-shkolu-chek-list` — 1 |
| `wechat-dlya-rossiyan-2026` — 215 за 23 дня | `marketplace-1688-alibaba` — 3 |
| `slovar-hsk-1-150-slov` — 837 | `kitayskiy-dlya-it-glossariy` — 7 |
| Массовый спрос, топ-5 по запросу | Узкая ниша либо рассказ о себе |

Проигравшие делятся на три типа: **коммерческие сравнения**
(«репетитор или школа», «как выбрать школу»), **узкие B2B-ниши**
(1688, глоссарий для IT) и **тексты о самой школе** (преподаватели, платформа,
лицензия). Возраст ни при чём: `professii` за 13 дней собрала больше, чем
`kitayskiy-dlya-it` за 41.

### Практическое редакционное правило

1. Тему выбирать по объёму спроса в Вебмастере, а не по интуиции.
2. Формат — информационный вопрос, на который есть однозначный фактический ответ.
3. Внутри — таблицы, FAQ, callout, разбор ошибок. Это повышает шанс удержаться в топе.
4. Коммерческие сравнения и тексты о школе не дают органики. Их место —
   посадочные страницы, а не блог.

### Главная проблема — не позиции, а CTR

Сайт уже стоит на позициях 4–9 по запросам с большим спросом и почти не получает
кликов. Примеры:

| китайский тоны | 1 312 | 2 | 0,2% | 4,0 |

Для сравнения — запросы, где заголовок точно отвечает на вопрос:

| Запрос | Показы | Клики | CTR | Позиция |

### Найденная и исправленная ошибка

Статья `chun-jie-2027-kogda-prazdnik` — крупнейший кластер спроса (9 888 показов) —
**указывала неверную дату**: 17 февраля 2027 вместо 6 февраля 2027
(17 февраля — это дата Чуньцзе 2026 года). Проверено двумя независимыми способами:
внешними источниками и арифметикой лунного календаря
(2026-02-17 + 354 дня = 2027-02-06; 2028-01-26 − 354 дня = 2027-02-06).

Исправлены дата праздника, канун, государственные выходные, 15-дневный календарь,
Праздник фонарей (20 февраля вместо 3 марта), деловые сроки отгрузок
и характеристика небесного ствола 丁 (инь-огонь, а не ян).

Это вероятная причина CTR 0,76% при позиции 6,1: сниппет противоречил остальной выдаче.
Пик спроса по этому кластеру придётся на декабрь — февраль.

### Глоссарий ранжируется, но не конвертирует

Страницы `/glossary/*` попадают в выдачу по крупным запросам, но приносят мало
трафика: `/glossary/pleco` — 85 визитов при 1 725 показах кластера,
`/glossary/confucius-institute` — 41 визит при 2 304 показах.
`palladiy`, `cantonese`, `putonghua` не входят даже в топ-28 посадочных.
Короткий формат словарной статьи не удерживает пользователя.
Решение — лонгрид в блоге со ссылкой на глоссарий, а не переписывание глоссария.

## 6. Что нужно починить отдельно

1. **Доступ к Google.** ADC существует (`~/.config/gcloud/application_default_credentials.json`),
   но выдан без нужных областей. Search Console и GA4 отвечают `403`.
   Владельцу нужно один раз выполнить локально:

   ```bash
   gcloud auth application-default login \
     --scopes=openid,https://www.googleapis.com/auth/cloud-platform,\
   https://www.googleapis.com/auth/webmasters.readonly,\
   https://www.googleapis.com/auth/analytics.readonly
   ```

   После этого `npm run seo:check` должен показать `[OK]` по всем четырём источникам,
   и анализ можно будет повторить с данными Google. Сейчас все выводы построены
   на Яндексе — для русскоязычного сайта это 85% органики, но Google-срез отсутствует.

2. **Битые внутренние ссылки.** Вебмастер показывает 81 пример, 43 уникальные цели,
   причина `DISALLOWED_BY_USER` — в основном пути `/dictionary/hsk/*/preload`
   и `/grammar/preload`. Отдельная задача, к блогу не относится.

3. **Заголовки существующих статей.** Отдельный быстрый выигрыш: переписать title
   и description у статей, стоящих на позициях 3–9 с CTR ниже 1%, под дословную
   формулировку запроса. Кандидаты — `4-tona-kitayskogo-poshagovo`
   («китайский тоны», 1 312 показов, 2 клика) и `skolko-ieroglifov-nuzhno-znat`.

## 7. Как повторить анализ

```bash
cd chinachild-site
npm run seo:check                                   # проверить доступы
npm run seo:collect -- --start=ГГГГ-ММ-ДД --end=ГГГГ-ММ-ДД
npm run seo:report                                  # summary.md + csv/
```

Ключевые файлы отчёта:

- `csv/yandex-organic-traffic.csv`, строки `view=landing_page` — трафик по статьям.
  Суммировать по `landing_page` через все значения `search_engine`: строки
  `total_search` в разрезе посадочных отсутствуют.
- `csv/yandex-search-performance.csv`, строки `view=popular_query`,
  `period=current`, `device=all` — спрос по запросам.
- `csv/search-opportunities.csv` — запросы на позициях 11–20 и со слабым CTR.

Нормировать трафик статьи на возраст (визиты в день) обязательно: без этого
свежие статьи выглядят провальными, а старые — успешными.

**Пополнять очередь до того, как она опустеет.** Двенадцать статей при графике
две в неделю — это шесть недель. Следующий цикл анализа и пополнения — начало ноября 2026.
